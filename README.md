# cv

Мій сайт-резюме: https://garkusha-cv.vercel.app

Статична сторінка на HTML і CSS, без фреймворків і збірки. Хоститься на Vercel, відвідуваність рахує Vercel Web Analytics. Скрипт аналітики віддає сам сайт з `/_vercel/insights/`, сторонніх CDN на сторінці немає.

- `index.html`: увесь вміст сторінки
- `style.css`: стилі, темна тема, адаптив під телефон
- `photo.jpg`: фото для першого екрана
- `preview.png`: картинка для прев'ю посилання в месенджерах
- `vercel.json`: заголовки безпеки

Оновлюю, коли змінюється досвід або навчання. Пуш у `main` одразу потрапляє на сайт.
